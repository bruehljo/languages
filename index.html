Auf iPhone & iPad nutzen

Lokal aus Files: Safari kann lokale HTML-Dateien nicht zuverlässig öffnen. Nutze stattdessen Edge oder Chrome, dort funktioniert es problemlos.

Wie eine echte App (Home-Bildschirm, eigenes Icon): Dafür braucht die Datei eine Web-Adresse. Mit GitHub geht das schnell:

  1. Neues Public Repository auf github.com anlegen, z.B. „sprachen".
  2. Dateien hochladen: spanisch.html (oder als index.html), icon.svg, icon-180.png, icon-192.png, icon.png, manifest.webmanifest.
  3. In Settings → Pages bei Source „Deploy from a branch", Branch main, Folder /(root) → Save.
  4. Nach 1–2 Minuten ist die App unter username.github.io/sprachen/ erreichbar.
  5. iPhone: URL in Safari öffnen → unten Teilen → Zum Home-Bildschirm. Das Icon erscheint mit „Hola/Olá/Bok".

Sobald die App einmal geladen ist, läuft alles offline weiter — auch ohne Netz.
